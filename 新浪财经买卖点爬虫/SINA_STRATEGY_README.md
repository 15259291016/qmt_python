# 新浪财经买卖点算法说明

## 算法基础：葛兰碧八大法则（Granville's Eight Rules）

新浪财经的买卖点主要基于**葛兰碧八大法则**，这是一种经典的移动平均线交易策略。

## 算法原理

### 买入点（B点）- 四个买入信号

#### B1点：均线突破买入
- **条件**：均线由下降转为水平或上升，且股价从均线下方突破均线
- **含义**：趋势反转，买入信号
- **代码逻辑**：
  ```python
  if (均线趋势从下降转为上升) and (前一日股价 < 均线) and (当日股价 > 均线):
      标记为B1买入点
  ```

#### B2点：回撤不破买入
- **条件**：均线上扬，股价上涨后回撤但未跌破均线，随后继续上涨
- **含义**：上升趋势中的回调买入机会
- **代码逻辑**：
  ```python
  if (均线上扬) and (股价回撤但未跌破均线) and (股价继续上涨):
      标记为B2买入点
  ```

#### B3点：跌破后反弹买入
- **条件**：均线上扬，股价跌破均线后再次上涨
- **含义**：假突破后的买入机会
- **代码逻辑**：
  ```python
  if (均线上扬) and (前一日股价 < 均线) and (当日股价 > 均线) and (价格上涨):
      标记为B3买入点
  ```

#### B4点：急跌反弹买入
- **条件**：股价急跌远离均线（通常>5%）后反弹接近均线
- **含义**：超跌反弹买入机会
- **代码逻辑**：
  ```python
  if (股价低于均线3%以上) and (距离在缩小) and (价格上涨):
      标记为B4买入点
  ```

### 卖出点（S点）- 四个卖出信号

#### S1点：均线跌破卖出
- **条件**：均线由上升转为水平或下降，且股价从均线上方跌破均线
- **含义**：趋势反转，卖出信号
- **代码逻辑**：
  ```python
  if (均线趋势从上升转为下降) and (前一日股价 > 均线) and (当日股价 < 均线):
      标记为S1卖出点
  ```

#### S2点：反弹不破卖出
- **条件**：均线下弯，股价反弹未突破均线后继续下跌
- **含义**：下降趋势中的反弹卖出机会
- **代码逻辑**：
  ```python
  if (均线下弯) and (股价反弹但未突破均线) and (股价继续下跌):
      标记为S2卖出点
  ```

#### S3点：突破后回落卖出
- **条件**：均线下弯，股价反弹突破均线后再次下跌
- **含义**：假突破后的卖出机会
- **代码逻辑**：
  ```python
  if (均线下弯) and (前一日股价 > 均线) and (当日股价 < 均线) and (价格下跌):
      标记为S3卖出点
  ```

#### S4点：急涨回落卖出
- **条件**：股价急涨远离均线（通常>5%）后回落接近均线
- **含义**：超涨回落卖出机会
- **代码逻辑**：
  ```python
  if (股价高于均线3%以上) and (距离在缩小) and (价格下跌):
      标记为S4卖出点
  ```

## 实现细节

### 均线周期
- 新浪财经通常使用**20日均线**（MA20）
- 也可以根据股票特性调整（如5日、10日、30日等）

### 均线趋势判断
- **上升趋势**：均线斜率 > 0
- **下降趋势**：均线斜率 < 0
- **水平趋势**：均线斜率 ≈ 0

### 价格与均线距离
- 使用百分比距离：`(价格 - 均线) / 均线 * 100`
- 用于判断"急涨"或"急跌"（通常阈值设为3-5%）

## 策略特点

### 优点
1. **简单易懂**：基于均线，逻辑清晰
2. **趋势跟踪**：能够捕捉主要趋势
3. **经典可靠**：经过市场验证的经典策略

### 缺点
1. **滞后性**：均线本身有滞后性，信号可能较晚
2. **震荡市表现差**：在横盘震荡市场中容易产生假信号
3. **单一指标**：仅基于均线，可能忽略其他重要信息

## 与优化策略的对比

| 特性 | 新浪风格（葛兰碧） | 优化策略（多指标） |
|------|------------------|------------------|
| 指标数量 | 1个（均线） | 6类（均线、MACD、RSI、KDJ、布林带、成交量） |
| 信号数量 | 较多 | 较少（更严格） |
| 信号质量 | 中等 | 较高（多指标确认） |
| 适用场景 | 趋势明显的市场 | 各种市场环境 |
| 计算复杂度 | 低 | 中高 |
